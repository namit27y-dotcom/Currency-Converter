# 💱 Currency Converter

A fast, responsive, and user-friendly currency converter built with **HTML, CSS, and JavaScript**. It uses live exchange-rate data to provide accurate currency conversions with a clean and responsive interface.

## 🚀 Live Demo

🔗 **[Try Currency Converter](https://currency-converter-ebon-eight.vercel.app/)**

## ✨ Features

- 🌍 Convert between multiple currencies
- ⚡ Live exchange rates
- 🔄 Swap source and target currencies instantly
- ⏱️ Debounced conversion requests
- 💾 Exchange-rate caching
- 🛡️ AbortController to prevent unnecessary API requests
- 🔌 Fallback API handling
- 🔄 Loading and error states
- 📱 Fully responsive design
- ♿ Accessible UI with ARIA/live labels
- 🕒 Displays when exchange rates were last updated

## 🛠️ Tech Stack

- **HTML5** — Structure
- **CSS3** — Styling and responsive design
- **JavaScript (ES6+)** — Application logic and API integration
- **REST API** — Live exchange-rate data
- **Git & GitHub** — Version control
- **Vercel** — Deployment
